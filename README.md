# VB Helper Data Extractor

APK extractor built using UnityPy.

Extracts JSON game data, .wav SFX/BGM, battle background PNGs, and attack sprite PNGs.

# Instructions
1. Download windows-vb-helper-data-extractor.exe from v1.0.0 releases.
2. Select APK with browse.
3. Extract the files.
4. Create a folder on your Android device's root storage if one doesn't already exist.
4. Copy the following folders to VBHelper folder:
- extracted_atksprites
- extracted_audio
- extracted_battlebgs
- extracted_digimon_stats
